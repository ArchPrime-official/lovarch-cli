## Step-by-step

### 1. Configure the Homebrew tap auto-bump token

The auto-bump workflow needs to open PRs in `ArchPrime-official/homebrew-lovarch`,
which the default `GITHUB_TOKEN` can't reach (it's scoped to the current repo).

1. https://github.com/settings/personal-access-tokens/new
2. Name: `lovarch-cli homebrew bump`
3. Expiration: 1 year (or `No expiration` if you want)
4. **Repository access**: Only select repositories → `homebrew-lovarch`
5. **Permissions** (Repository):
   - Contents: **Read and write**
   - Pull requests: **Read and write**
   - Metadata: Read (auto-granted)
6. Generate, copy the `github_pat_...` token

```bash
gh secret set HOMEBREW_TAP_TOKEN --repo ArchPrime-official/lovarch-cli
# Paste the token when prompted
```

Verify:

```bash
gh secret list --repo ArchPrime-official/lovarch-cli
# Should show HOMEBREW_TAP_TOKEN with a recent updatedAt
```

> Skip this step? Fine — the auto-bump workflow exits gracefully with a
> `::notice::` log entry. You'd then bump the tap manually:
> ```bash
> cd /Users/pablo/homebrew-lovarch
> # Edit Formula/lovarch-cli.rb: url to new tag, sha256 to new hash
> curl -sL <new-tag-tarball-url> | shasum -a 256
> git commit -am "bump: lovarch-cli 0.1.0" && git push
> ```

### 2. Bump version + tag

```bash
cd /Users/pablo/lovarch-cli
git checkout main && git pull
```

Edit `lovarch_cli/version.py`:

```python
__version__ = "0.1.0"    # was "0.1.0-beta.1"
```

Edit `CHANGELOG.md`: move items under `[Unreleased]` to a new `[0.1.0]`
section above. Update the compare-link footer:

```markdown
[Unreleased]: https://github.com/ArchPrime-official/lovarch-cli/compare/v0.1.0...HEAD
[0.1.0]: https://github.com/ArchPrime-official/lovarch-cli/compare/v0.1.0-beta.1...v0.1.0
[0.1.0-beta.1]: https://github.com/ArchPrime-official/lovarch-cli/releases/tag/v0.1.0-beta.1
```

Then:

```bash
git commit -am "chore: bump v0.1.0

Release notes summarized in CHANGELOG.md [0.1.0].
"
git tag v0.1.0
git push origin main v0.1.0
```

### 3. Watch the automation

Open three browser tabs:

1. **GitHub Release**: https://github.com/ArchPrime-official/lovarch-cli/releases
2. **attach-to-release run**: https://github.com/ArchPrime-official/lovarch-cli/actions/workflows/attach-to-release.yml
3. **Homebrew bump PR**: https://github.com/ArchPrime-official/homebrew-lovarch/pulls

Expected outcomes within ~3 minutes of the tag push:

- ✅ `attach-to-release.yml` creates the GitHub Release `v0.1.0` with
  `lovarch_cli-0.1.0-py3-none-any.whl` + `lovarch_cli-0.1.0.tar.gz` attached
- ✅ `bump-homebrew-formula.yml` opens a PR in `homebrew-lovarch` titled
  "bump: lovarch-cli 0.1.0" with the new SHA256

> `publish-pypi.yml` does NOT run anymore on tag push — it was changed to
> `workflow_dispatch` (manual). Activate it later if you decide to publish
> to PyPI.

### 4. Merge the Homebrew bump PR

```bash
gh pr list --repo ArchPrime-official/homebrew-lovarch
# Sanity check: SHA256 in the PR matches the one in the released tarball
gh pr view <N> --repo ArchPrime-official/homebrew-lovarch
# CI must be green (brew install --build-from-source + brew test passed)
gh pr merge <N> --repo ArchPrime-official/homebrew-lovarch --squash --delete-branch
```

After merge:

```bash
# Test from a fresh shell (or just untap + retap)
brew untap archprime-official/lovarch 2>/dev/null || true
brew tap archprime-official/lovarch
brew install lovarch-cli
lovarch --version   # → lovarch-cli 0.1.0
```

### 5. Test pipx install (independent path)

```bash
pipx install git+https://github.com/ArchPrime-official/lovarch-cli.git@v0.1.0
lovarch --version
```

If that's clean, you have two working install channels.

## Activating PyPI later (if/when you want it)

When you eventually have time + interest:

1. Create the account: https://pypi.org/account/register/ with 2FA
2. Reserve the name with one manual upload:
   ```bash

   python -m pip install --upgrade build twine
   python -m build
   twine upload dist/*   # prompts for token
   ```
3. Create a project-scoped token: https://pypi.org/manage/account/token/
4. Add the secret: `gh secret set PYPI_API_TOKEN --repo ArchPrime-official/lovarch-cli`
5. Either:
   - Manually trigger publish for a tag:
     ```bash
     gh workflow run publish-pypi.yml --ref v0.1.0 -f tag=v0.1.0
     ```
   - OR edit `.github/workflows/publish-pypi.yml` to add `on: push: tags: ['v*']`
     so future releases auto-publish.

## Troubleshooting

### Homebrew bump PR not created

→ `HOMEBREW_TAP_TOKEN` missing or wrong scope. Job exits with `::notice::`.
Fix the secret then re-run:

```bash
gh workflow run bump-homebrew-formula.yml \
  --repo ArchPrime-official/lovarch-cli \
  --ref v0.1.0
```

### Wheel attach failed

The workflow rebuilds from the tag. If `python -m build` fails, the most
likely cause is `lovarch_cli/version.py` mismatch — verify the tag matches
the declared `__version__`. Push a corrected tag with a force-tag:

```bash
git tag -d v0.1.0 && git push origin :v0.1.0
git tag v0.1.0 && git push origin v0.1.0
```
